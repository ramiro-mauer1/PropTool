# 🛠️ Resumen de Skills Disponibles

Este documento detalla brevemente las **skills** disponibles en el entorno y el propósito de cada una.

---

## 🎨 Diseño Visual, UI/UX y Frontend

| Skill | Descripción |
| :--- | :--- |
| **`design-taste-frontend`** | Diseño frontend de alto nivel ("anti-slop") para landing pages, portafolios y rediseños. Evita componentes genéricos o plantillas predecibles. |
| **`design-taste-frontend-v1`** | Versión legacy v1 del skill de diseño frontend para compatibilidad con proyectos existentes. |
| **`high-end-visual-design`** | Estándares de diseño de agencias de lujo (tipografía refinada, jerarquía espacial, sombras sutiles y acabados prémium). |
| **`minimalist-ui`** | Interfaces limpias de estilo editorial (paletas monocromáticas cálidas, contraste tipográfico, bento grids planos, sin degradados excesivos). |
| **`industrial-brutalist-ui`** | Interfaces técnicas y mecánicas inspiradas en el diseño suizo y terminales industriales/militares (blueprints, rejillas rígidas y alto contraste). |
| **`emil-design-eng`** | Filosofía de pulido de UI de Emil Kowalski (microinteracciones, animaciones fluidas y detalles que mejoran la experiencia de usuario). |
| **`gpt-taste`** | Diseño UI avanzado con animaciones complejas usando **GSAP** (ScrollTriggers, bento grids dinámicos y tipografía editorial de gran escala). |
| **`impeccable`** | Auditoría, pulido, accesibilidad y refinamiento integral de interfaces (landing pages, dashboards, aplicaciones y componentes). |
| **`redesign-existing-projects`** | Modernización y mejora estética de proyectos existentes a estándares modernos sin romper la funcionalidad previa. |
| **`stitch-design-taste`** | Generación de sistemas de diseño semánticos (`DESIGN.md`) para Google Stitch con directrices visuales y de movimiento. |
| **`generative_ui`** | Creación y renderizado de widgets interactivos en HTML/JS para visualizaciones de datos, diagramas y componentes interactivos inline. |
